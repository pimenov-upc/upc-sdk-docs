`UpcService` - є базовим абстрактним класом. Від нього наслідуються всі інші класи (виключення UpcSignService).

Сігнатура класу:
```ts
abstract class UpcService {
  constructor(
    resource: string, 
    protected readonly options: UpcServiceOptions
  ) {
    ...
  }
  ...
}
```

Приклад наслідування:
```ts
class UpcBinService extends UpcService {
  constructor(
    resource: string, 
    protected readonly options: UpcServiceOptions) 
  {
    super(resource, options)
  }
  ...реалізація методів класу
}
```

:::note
Створити екземпляр класу `UpcService` напряму неможливо.
:::

### Параметри конструктора

- `resource` - середовище, в якому будуть відбуватися запити
- `options` - додаткові опції 

#### Середовище (resource)

Перший аргумент конструктора визначає середовище:

| Значення       | Базова URL-адреса         |
| -------------- | ------------------------- |
| `'test'`       | `https://ecg.test.upc.ua` |
| `'production'` | `https://secure.upc.ua`   |

Використовуйте `'test'` під час розробки. Запити до `'production'` можуть виконувати реальні операції.

Замість назви середовища можна передати власну базову HTTPS URL. Вона має бути без шляху, query-параметрів і фрагмента; клієнт сам додає шлях API.

#### Додаткові опції (options)

Додаткові параметри описуються інтерфейсом `UpcServiceOptions` і мають наступні члени:

| Параметр     | Обов’язковий | Типове значення | Опис                                                                                                 |
| ------------ | ------------ | --------------- | ---------------------------------------------------------------------------------------------------- |
| `merchantId` | Так          | —               | Ідентифікатор продавця.                                                                              |
| `terminalId` | Так          | —               | Ідентифікатор термінала.                                                                             |
| `privateKey` | Ні          | —               | Приватний ключ для підписання запиту.                                                                |
| `passphrase` | Ні          | —               | Пароль приватного ключа.                                                                             |
| `publicKey`  | Ні          | —               | Публічний ключ для перевірки відповіді UPC.                                                          |
| `timeout`    | Ні           | `60000` мс      | Час очікування HTTP-запиту.                                                                          |
| `logging`    | Ні           | `false`         | Увімкнути діагностичне журналювання.                                                                 |
| `returnType` | Ні           | `'json'`        | Якщо значення точно `'json'`, відповідь XML перетворюється на об’єкт; інакше повертається XML-рядок. |

Приклад створення екземпляру класу, який наслідує `UpcService`:

```ts
const binInfo = new UpcBinInfo('test', {
  merchantId: 'your-merchant-id',
  terminalId: 'your-terminal-id',
  privateKey: 'path/to/your-private-key',
  passphrase: 'your-passphrase',
  publicKey: 'path/to/server-public-key-or-certificate',
});
```

### Методи класу

Базовий клас має наступні захищені (protected) методи:

- `merchantPayload()` - додає в корисне навантаження значення MerchantId, TerminalId
- `isJsonResponse()` - перевіряє чи є значення відповідним до формату UPC `{header, payload, signature}`
- `sendXml()` - відправляє XML запит
- `sendJson()` - відправляє JWS запит
- `resolveXmlResponse()` - перевіряє і повертає результат XML запиту
- `resolveJsonResponse()` - перевіряє і повертає результат JWS запиту

#### merchantPayload()

Метод додає до параметрів запиту значення `MerchantId` та `TerminalId`.

```ts
async getBinInfoXml(bin: string, trackingId?: string): Promise<any> {
  const payload: XmlObject = {
    ...this.merchantPayload(),
    TrackingId: trackingId ?? `${Date.now()}`,
    GetBinInfo: {
      Bin: bin,
    },
  };
  ...
}
```

#### isJsonResponse()

Метод перевіряє, чи є відповідь сервера в форматі JWS, а саме чи є відповідь об'єктом з полями `header`, `payload` та `signature`.
Метод використовується в методі `sendJson()` для перевірки відповідності формату запиту.

Сігнатура метода:

```ts
protected isJsonResponse(
  value: unknown
): value is UpcJsonResponse {}
```

#### sendXml()

Метод використовується для відправлення на сервер запиту в форматі XML.

Сігнатура метода:
```ts
protected async sendXml(
  endpoint: string, 
  xml: string
): Promise<UpcXmlResponse> {}
```

#### sendJson()

Метод використовується для відправлення на сервер запиту в форматі JWS.

Сігнатура метода:
```ts
protected async sendJson(
  endpoint: string,
  json: JsonObject | UpcJsonRequest
): Promise<UpcJsonResponse | UpcJsonResponseString> {}
```

#### resolveXmlResponse()

Метод перевіряє підпис відповіді сервера (за наявності публічного ключа чи сертифіката сервера) та повертає результат в залежності від параметра `returnType`.
Необов'язковий параметр `operation` слугує для конретизації операції у випадку помилки.

Сігнатура метода:
```ts
protected resolveXmlResult(result: any, operation: string = ''): any {}
```

#### resolveJsonResponse()

Метод перевіряє підпис відповіді сервера (за наявності публічного ключа чи сертифіката сервера) та повертає декодований результат.
Необов'язковий параметр `operation` слугує для конретизації операції у випадку помилки.

Сігнатура метода:
```ts
protected resolveJsonResult(result: any, operation: string = ''): any {}
```
