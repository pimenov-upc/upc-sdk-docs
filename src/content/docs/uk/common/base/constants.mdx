Модуль `@upc/common` експортує декілька констант, які використовуються в артефактах, та які ви також можете використовувати за потреби.

### UPC_RESOURCE

Константа, яка визначає тестове та робоче середовища UPC E-Commerce.

```ts
export const UPC_RESOURCE = {
  Test: 'https://ecg.test.upc.ua',
  Production: 'https://secure.upc.ua',
} as const;
```

### UPC_RETURN_TYPE

Константа, яка визначає повертаємий формат відповіді сервера.

```ts
export const UPC_RETURN_TYPE = {
  JSON: 'json',
  XML: 'string',
  RAW: 'raw',
} as const;
```

### UPC_ENDPOINT

Константа, яка визначає кінцеві точки для запитів.

```ts
export const UPC_ENDPOINT = {
  createToken: '/go/token/create',
  refreshToken: '/go/token/refresh',
  deleteToken: '/go/token/delete',
  getTokenStatus: '/go/token/status',
  suspendToken: '/go/token/suspend',
  resumeToken: '/go/token/resume',
  getCardContent: '/go/card/content',
  getCardMetadata: '/go/card/metadata',
  threeDS2: '/go/service/3ds/v2.2',
  checkoutXml: '/go/service/02',
  payByToken: '/go/payByToken',
  postAuthorization: '/go/capture',
  transactionStatus: '/go/service/01',
  repayment: '/go/repayment',
} as const;
```

### UPC_HOST_CODE

HostCode - це код відповіді  ISO8583 хоста UPC. 
Код більш деталізований і може бути виконаний для додаткового аналізу причин відкладання транзакцій. 
Код додається у відповідь лише тоді, коли хост UPC повертає відповідь.

Детальніше дивіться в розділі [Коди HostCode](../../codes/host-codes)

Для отримання необхідного значення слід використовувати функцію `resolveHostCode(code, locale)` (функція експортується модулем `@upc/common`).
Значення за замовчення для параметра `locale` становить `uk`.

```ts
import { resolveHostCode } from '@upc/common';

const status = resolveHostCode('000', 'en');
console.log(status);
```
Вивід console.log буде:
```json
{
  code: '000',
  name: 'Transaction approved' 
}
```

### UPC_TRAN_CODE

TranCode є основним кодом відповіді шлюзу і доступний у кожній відповіді.

Детальніше дивіться в розділі [Коди TranCode](../../codes/transaction-codes)

Для отримання необхідного значення слід використовувати функцію `resolveTranCode(code, locale)` (функція експортується модулем `@upc/common`).
Значення за замовчення для параметра `locale` становить `uk`.

```ts
import { resolveTranCode } from '@upc/common';

const status = resolveTranCode('000', 'en');
console.log(status);
```

Вивід console.log буде:
```json
{
  code: '000',
  name: 'Transaction successful' 
}
```
