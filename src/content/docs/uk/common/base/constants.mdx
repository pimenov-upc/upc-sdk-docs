Модуль `@upc/common` експортує декілька констант, які використовуються в артефактах, та які ви також можете використовувати за потреби.

### UPC_RESOURCE

Константи, які визначають тестове та робоче середовища UPC E-Commerce.

```ts
export const UPC_RESOURCE = {
  Test: 'https://ecg.test.upc.ua',
  Production: 'https://secure.upc.ua',
} as const;
```

### UPC_RETURN_TYPE

Константи, які визначають повертаємий формат відповіді сервера.

```ts
export const UPC_RETURN_TYPE = {
  JSON: 'json',
  XML: 'string',
  RAW: 'raw',
} as const;
```

Для отримання необхідного значення слід використовувати функцію `resolveHostCode(code, locale)` (функція експортується модулем `@upc/common`).
Значення за замовчення для параметра `locale` становить `uk`.

```ts
import { resolveHostCode } from '@upc/common';

const status = resolveHostCode('000', 'en');
console.log(status);
```
Вивід console.log буде:
```json
{
  code: '000',
  name: 'Transaction approved' 
}
```
