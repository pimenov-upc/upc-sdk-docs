`TranCode` є основним кодом відповіді шлюзу і доступний у кожній відповіді.

| Код | Опис |
| --- | --- |
| `000` | Успішна транзакція |
| `002` | Часткова авторизація |
| `004` | Затверджено DCC |
| `101` | Неправильні параметри карти |
| `105` | Не затверджено емітентом |
| `108` | Загублена/викрадена карта |
| `111` | Неіснуюча карта |
| `116` | Недостатньо коштів |
| `130` | Перевищено ліміт по карті |
| `131` | Потрібна додаткова автентифікація клієнта |
| `290` | Емітент недоступний |
| `291` | Технічні проблеми/проблеми зі зв'язком |
| `401` | Неправильний формат |
| `402` | Невірні дані еквайра/продавця |
| `403` | Збій зв'язку компонентів |
| `404` | Помилка аутентифікації |
| `405` | Підпис недійсний |
| `406` | Перевищена квота транзакцій |
| `407` | Продавець не активний |
| `408` | Транзакція не знайдена |
| `409` | Знайдено забагато транзакцій |
| `410` | Замовлення сплачено (можливий повтор) |
| `411` | Час запиту замовлення застаріло |
| `412` | Умова порядку відтворення |
| `413` | Невідомий тип карти |
| `414` | Необхідний CVC/CVV код |
| `415` | План розстрочки не знайдено |
| `420` | Загальна кількість успішних транзакцій в день обмежена |
| `421` | Обмеження суми транзакції (без повної аутентифікації 3-D Secure) |
| `430` | Транзакція заборонена шлюзом |
| `431` | Спроба 3D-Secure не приймається |
| `432` | Карта в стоп-списку |
| `433` | Кількість транзакцій перевищила ліміт |
| `434` | Магазин не приймає карти з країни |
| `435` | IP-адреса клієнта в стоп-аркуші |
| `436` | Сума транзакцій перевищила ліміт |
| `437` | Перевищено ліміт введення кількості карт |
| `438` | Неприпустимий код валюти |
| `439` | Перевищено термін від запиту до авторизації |
| `440` | Перевищено ліміт часу авторизації |
| `441` | Проблема взаємодії MPI |
| `442` | Проблема зв'язку ACS |
| `443` | Проблема зв'язку з ActiveServer |
| `444` | Параметр NameOnCard недійсний або порожній |
| `450` | Рекурентні платежі заборонені |
| `451` | Служба MPI не включена |
| `452` | Платіж з карти на карту не включений |
| `453` | Сервіс Airline Addendum не ввімкнено |
| `454` | Сервіс REF3 не ввімкнено |
| `455` | Сервіс погашення не ввімкнено |
| `460` | Token service не включений |
| `469` | Транзакцію заборонено антифрод-системою |
| `501` | Скасовано користувачем |
| `502` | Термін дії веб-сеансу минув |
| `503` | Транзакція скасована продавцем |
| `504` | Транзакція була скасована шлюзом зі скасуванням |
| `505` | Невірна послідовність операцій |
| `506` | Термін дії попередньої авторизації минув |
| `507` | Попередньо авторизована транзакція вже оброблена з платежем |
| `508` | Невірна сума для оплати попередньо авторизованої транзакції |
| `509` | Неможливо повернутися до вихідної транзакції |
| `510` | Термін повернення минув |
| `511` | Транзакція скасована розрахунковим дією |
| `512` | Повторне анулювання або повернення |
| `513` | Термін дії рахунку завершився |
| `601` | Не завершено |
| `602` | Очікування підтвердження платежу |
| `603` | Очікується автентифікація клієнта |
| `606` | Платіж через PayByBank (A2A) оброблено поза Paylink |
| `701` | Обмеження з боку хоста/платіжної системи |
| `902` | Неможливо обробити транзакцію |
| `903` | Транзакцію потрібно ввести повторно |
| `904` | Отримане повідомлення не відповідає стандартам |
| `908` | Невизначений код 908 |
| `909` | Невизначений код 909 |
| `910` | Невизначений код 910 |
| `999` | Транзакція в процесі .. (проміжний статус, ви повинні відправити запит на статус платежу до остаточного статусу) |
