HostCode - це код відповіді `ISO8583` хоста UPC. 
Код більш деталізований і може бути виконаний для додаткового аналізу причин відкладання транзакцій. 
Код додається у відповідь лише тоді, коли хост UPC повертає відповідь.

| `002` | Затверджено на часткову суму |
| `004` | Відповідь DCC |
| `010` | Потрібна додаткова аутентифікація клієнта (чіп і PIN-код або SCA) |
| `011` | Потрібно PIN-код |
| `100` | Відмова без уточнення причини |
| `101` | Невірний термін дії карти/термін дії карти вичерпано |
| `102` | Підозра у шахрайстві |
