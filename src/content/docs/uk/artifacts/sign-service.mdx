Сервіс `UpcSignService` відповідає за підписання запитів клієнта і валідацію відповідей сервера.
Сервіс представлений класом `UpcSignService`.

## Встановлення

Для встановлення необхідно виконати команду:

```shell
npm i @upc/sign-service
```

:::note
Всі артефакти сервісів SDK вже мають в собі `UpcSignService` і вміють підписувати запити і верифікувати відповіді.
:::

## Методи

Клас `UpcSignService` надає статичні методи для підписання запитів і перевірки відповідей.

- `sign()` - підписання JSON запитів
- `signXml()` - підписання XML запитів
- `verify()` - перевірка JSON/String відповідей
- `verifyXml()` - перевірка XML відповідей

## Алгоритми

Для підписання можливо використовувати наступні алгоритми:

- `SHA256` - значення для параметра `RS256` (значення за замовченням)
- `SHA512` - значення для параметра `RS512`

## JSON (JWS)

Для роботи з даними в форматі `JWS` призначені методи `sign()` та `verify()`.

### Підписання JWS

Для підписання JSON об'єкта і формування JWS необхідно викликати метод `sign(...)` з відповідними параметрами.

```ts
const payload = {
  merchantId: '1750000',
  terminalId: 'E1750000',
}
const privateKey = 'path/to/private/key'
const passphrase = 'private_key_password'
const algorithm = 'RS256'

const signedPayload = UpcSignService.sign(
  payload, 
  privateKey, 
  passphrase, 
  algorithm
)
```

Після підписання ви отримуєте закодований в `Base64Url` JSON/JWS об'єкт формату:

```json
{
  header: {...},
  payload: {...},
  signature: {...}
}
```

### Верифікація відповіді JWS

Якщо сервер розпізнав ваш запит (за допомогою завантаженого в UPC вашого публічного ключа або сертифікату), він так само формує навантаження і підписує його.
Для перевірки того, що ви дійсно отримали відповідь від довіреного сервера, необхідно верифікувати відповідь.
Верифікація відповіді в форматі JWS здійснюється за допомогою метода `verify()`.

```ts
// publicKey - шлях до сертифікату або публічного ключа сервера
const result = ... // відповідь сервера
const verifier = UpcSignService.verify(result, publicKey)

if (!verifier) {
  throw new Error('Помилка верифікації');
}

// ... подальші дії з отриманою відповіддю
```

## XML

Для роботи з даними в форматі `XML` призначені методи `signXml()` та `verifyXml()`.

### Підписання XML

Для підписання Xml об’єкта необхідно викликати метод signXml(...) з відповідними параметрами.

```ts
const xml = ... // raw xml string
const signedXml = UpcSignService.signXml(
  payload, 
  privateKey, 
  passphrase, 
  algorithm
)
```

### Перевірка XML відповіді

Щоб перевірити достовірність відповіді (що відповідь прийшла від довіреного серверу), необхідно використати метод `verifyXml()`.

```ts
// publicKey - шлях до сертифікату або публічного ключа сервера
const xml = ... // відповідь сервера
const verifier = UpcSignService.verifyXml(xml, publicKey)

if (!verifier) {
  throw new Error('Помилка верифікації');
}

// ... подальші дії з отриманою відповіддю
```
