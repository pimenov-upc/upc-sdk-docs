| Значення       | Базова URL-адреса         |
| -------------- | ------------------------- |
| `'test'`       | `https://ecg.test.upc.ua` |
| `'production'` | `https://secure.upc.ua`   |

Використовуйте `'test'` під час розробки. Запити до `'production'` можуть виконувати реальні операції.

Замість назви середовища можна передати власну базову HTTPS URL (там де це підтримується). 
Вона має бути без шляху, query-параметрів і фрагмента; клієнт сам додає шлях API.
