API BinInfo represents with a class `UpcBinInfo`. To use this class you must create new instance of it.

```ts
const binInfo = new UpcBinInfo({...})
```

## Constructor parameters

Params for the `constructor` defined with interface `UpcServiceOptions`:

```ts
interface UpcServiceOptions {
  merchantId: string;
  terminalId: string;
  privateKey: string;
  passphrase: string;
  publicKey: string;
  timeout?: number;
  logging?: boolean;
  returnType?: string;
  algo?: unknown;
}
```

If you sets `privateKey`, [`passphrase`] and `publicKey`, request will be sent with signing and answer will be checked with verifier.

## Methods

Ro get bin information you can use two methods:

- `getBinInfoXml(bin, trackingId)` - for the xml request
- `getBinInfo(bin, trackingId)` - for the json request (this API in the developing)

```ts
const binInfo = new UpcBinInfo({
  merchantId: '1750000',
  terminalId: 'E1750000',
  privateKey: 'path/to/your/private/key',
  passphrase: 'private_key_passphrase',
  publicKey: path/to/server/certificate
})

const result = binInfo.getBinInfoXml('512070', 'get-bin-1');
console.log(result);
```

## JSON Response (default)

On response you get object with result:

- if success, JSON object with all info about specified bin
- if error, JSON object with received error

## XML Response

To get response as raw xml, you must set option `returnType` to `raw` or `string`.

```ts
const binInfo = new UpcBinInfo({
  ...,
  returnType: 'raw'
})
```
